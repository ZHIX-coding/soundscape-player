# 声境 · Soundscape

面向在学习或休息时听音乐的学生。学生可以从封面或曲目列表挑选作品，把适合一起听的曲目整理成歌单，再进入专注阅读或大字舞台。默认展示空间封面，曲库工具栏可以切换到紧凑列表，浏览器记住上次选择。

## 本地运行

本次在 Node.js 24.18.1 和 npm 11.16.0 上验证。安装 Node.js 24 后，在本目录执行：

```sh
npm install
npm run dev
```

打开终端输出的本地地址。音轨与封面包含在工程中。运行期无需账号、在线音乐服务或素材生成工具。

## 构建与检查

```sh
npm run lint
npm run build
npm run preview
```

构建目录为 `dist/`，由 HTTP 静态服务提供。哈希路由支持从分享的歌单地址刷新进入。歌单内容保存在创建它的浏览器与站点地址下，开发服务和预览服务有各自的存储。

保留预览服务，在第二个终端执行 `npm run test:browser` 可重走阶段演示和异常恢复流程，刷新 `screenshots/` 中的页面截图。测试需要已安装桌面 Chrome，默认预览地址为 http://127.0.0.1:4173。可用环境变量 `PREVIEW_URL` 指向其他端口，`BROWSER_CHANNEL=msedge` 可选择已安装的 Edge。测试使用独立的临时浏览器上下文。`npm run format` 可统一前端源码格式。

## 页面、数据与交互

空间展厅提供镜廊、环轨和唱片墙三种布局，三者共用搜索结果与选中曲目。左右键或滑动切换封面，选中后按播放可试听。切换布局会记住偏好并保留播放进度。歌单卡与详情使用最多四张不同的实际封面拼合，来自同一专辑的歌曲共用一张图。

| 页面 | 现场可操作的功能 |
| --- | --- |
| 曲库 `/#/library` | 点击侧方封面切换选曲，点击中央封面播放。用按钮、左右键或滑动翻阅封面。按斜杠聚焦搜索，组合搜索和风格筛选，按时长或曲名排序。曲目行可以收藏、加入队列或歌单。 |
| 我的音乐 `/#/my` | 查看收藏、创建歌单。名称去除首尾空格，校验必填、24 字符上限和同名，错误显示在字段旁。 |
| 歌单详情 `/#/playlist/:id` | 搜索歌单内歌曲，增删曲目，编辑名称、简介或确认删除歌单。播放全部将歌单顺序复制到队列。 |
| 播放舞台 `/#/player` | 阅读模式并排显示封面与歌词；舞台模式使用封面背景与居中歌词。点击某行跳到对应人声起点。器乐显示纯音乐状态。 |

曲库的「导入歌曲」支持一次选择一份音频，选填歌手、LRC 和专辑图。支持普通逐行 LRC 和带 `<mm:ss.xx>` 词级时间标签的增强 LRC。导入完成即可播放并加入歌单；浏览器用 IndexedDB 保存音频、图片和歌词。滚动或滑动歌词可停留浏览并查看每句起点，点「回到当前句」恢复跟随，直接点歌词可跳到该句。舞台右上角可以进入全屏，支持全屏的浏览器也可以按 Esc 退出。队列支持上下调整顺序，并保存到下次打开。

底栏提供播放、暂停、切歌、进度、音量、队列和播放模式。手机底栏可直接拖动进度，队列面板也可以调节进度和音量。舞台右上角的外观面板可以放大歌词、切换柔焦背景或减少动效，这些偏好随刷新保留。顺序播放到最后一首时停止，单曲循环重播当前曲目，随机模式在多个候选项中排除当前曲目。刷新恢复上一首、队列、设置和时间，等待用户点击后播放。

## 实现与数据来源

### 接入后台曲库

在项目根目录的 `.env.local` 中设置 `VITE_CATALOG_URL=/api/songs`，开发时重启服务，生产部署时重新构建。前端启动时 GET 这个地址，在线曲目按接口顺序出现在内置曲目前面。本地导入的文件仍保存在当前浏览器。后台新增或更新歌曲后，刷新页面即可取得曲库。

接口返回 JSON，例如下面这条用现有素材即可试听的记录。

```json
{
  "songs": [
    {
      "id": "folk-001",
      "title": "茉莉花",
      "artist": "Lindy Lin",
      "genre": "中文民歌",
      "audio": "/media/jasmine.mp3",
      "cover": "/media/jasmine.webp",
      "duration": 48.573,
      "lrc": "[00:00.08]好一朵美丽的茉莉花\n[00:06.84]好一朵美丽的茉莉花"
    }
  ]
}
```

必填字段为稳定且唯一的 `id`、`title` 和可播放的 `audio` 地址。时长单位为秒。省略封面时使用项目备用封面；省略歌词时仍可播放，器乐可传 `"vocal": false`。字段 `lrc` 接受普通或增强 LRC 正文。示例只列了两句，逐字同步需提供字词起点。媒体的相对地址以接口最终 URL 为基准。跨域接口与需要提取点阵的跨域封面应允许播放器站点读取。曲库服务暂时失败时会尝试显示此前缓存的曲目资料，音频仍从原地址播放。收藏、队列和个人歌单目前保存在浏览器。

采用 Vue 3、Vite、JavaScript、Vue Router、Pinia、CSS 媒体查询、Git、ESLint、Prettier。组件图标来自 Lucide。中文民歌《茉莉花》使用 Lindy Lin 的现场清唱录音。三首英文人声录音来自 Josh Woodward 的《The Wake》，另有六首项目生成的器乐。录音授权、歌词来源和素材重建步骤见 [素材说明](docs/素材.md)。

- `src/main.js` 注册四个页面，动态路径携带歌单 ID。
- `src/stores/music.js` 包含播放器和个人曲库两个 store。播放器独占一个 HTMLAudioElement。切页只改变视图。收藏和歌单引用曲目 ID，去重后存入带版本号的 localStorage。
- `src/pages/Library.vue` 在 computed 中对曲库做筛选和排序，`src/components/SongTable.vue` 将结果渲染为统一的可操作列表。详情和收藏复用同一组件。
- `src/components/LyricsPanel.vue` 依据实际音频进度找到最后一条已开始的歌词，定位并高亮。有词时间戳时，在下一词起点重新读取音频时钟，切换高亮。暂停和拖动会重新定位，只有行级数据的曲目沿用整行高亮。系统开启减少动态效果时，切换和滚动相应简化。
- `src/components/PlaylistForm.vue` 收集输入，由 store 统一校验与保存。曲库、收藏和歌单视图共享即时更新。
- `src/data/songs.js` 保存曲名、艺术家、风格、时长、相对资源位置、颜色和歌词。新增曲目时同步加入音轨和封面。
- `scripts/check-browser.mjs` 使用 Playwright 操作正式界面，包括断开一首音频的请求后重试。

## 阶段验收与已知限制

[开发与验收记录](docs/阶段验收.md) 包含真实验证范围与答辩演示路径。预置十首曲目，其中《茉莉花》有八行逐字跟唱歌词，Golden Sunrise 自带逐行同步歌词。导入的歌曲可配本地 LRC。收藏和歌单依赖当前浏览器存储，清除站点数据后会清空。已检查手机尺寸的浏览器视口，实际手机扬声器、耳机与投影设备的听感和可读性仍需小组现场确认。

## 小组分工与工具使用

成员名单、实际分工、个人提交和个人总结待小组按真实开发情况填写。建议每名成员记录自己修改的文件、对应功能、验证结果和可现场解释的实现。当前版本为 AI 辅助开发的阶段基线，涉及工程搭建、页面、状态管理、演示素材、回归验证与文档。Folia 的观察来自原项目交接文件，视觉借鉴范围为空间陈列、歌词构图、封面驱动背景与常驻播放控制。
