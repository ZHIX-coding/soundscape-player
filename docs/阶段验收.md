# 阶段验收与开发记录

## 2026-11-13 起始版本

核对原课程说明 18 页和《项目方案与开发交接.md》，在仅有两份资料的目录中建立 Vue 工程，初始化 Git。实现曲库、个人收藏和歌单、歌单详情及歌词舞台，并加入本地媒体。用户已确认首屏使用空间封面展厅，下方接可操作的曲目列表，可在曲库切换。原始资料保留在根目录。

## 已执行的浏览器验收

在本机 Chrome 加载生产预览。自动化操作覆盖以下路径，可用 README 中的命令重跑。

- 桌面 1440 × 900 曲库、翻阅封面，搜索加风格筛选得到空结果后清除条件，按时长检查首条结果。
- 在歌曲操作菜单创建歌单，提交空名称触发校验，带首尾空格的名称经清理后显示。在详情添加第二首，播放全部。
- 播放中进入舞台，点第三行歌词，验证当前行和跳转后的进度；切换舞台模式，刷新验证暂停、进度与模式恢复。
- 播放至结束事件后按顺序换曲，单曲循环模式回到开头；在两首歌的队列中随机切歌，移出歌曲并重新加入。
- 歌单移除、改名、确认删除；不存在的详情地址有返回入口。构造损坏的本地收藏数据后重新进入，页面正常加载。
- 查看 390 × 844 手机视口，确认底栏和曲库布局，在队列内调节音量；检查 320 像素宽曲库无水平溢出。
- 拦截一首音频的请求，界面报告失败，恢复请求后一次点击可重试。测试期间未出现未捕获的页面异常。

首次视觉检查发现生产预览中的背景未正确呈现，改为独立封面图片层并交叉淡入。故障注入发现播放失败后可能要多点一次，已依据真实音频错误状态修复。页面截图位于 `screenshots/`。

## 小组演示建议（约五分钟）

1. 用半分钟说明学生在自习和休息时整理音乐、减少切页打断的需求。
2. 搜索「Golden」，收藏并从曲目菜单新建「夜读」歌单，先提交一次空名称。进入详情，加上《Crazy Glue》并播放全部。
3. 保持播放进入舞台，点击一行歌词，切换阅读与舞台。返回曲库后从底栏观察时间继续前进。刷新演示本地恢复。
4. 打开播放器 store 说明音频事件与状态，再打开歌词页面说明时间定位。打开歌单表单演示如何更改名称长度规则。
5. 预留时间由真实模块负责人说明个人修改与测试，并记录课堂反馈。教师阶段验收及每位成员的答辩由小组实际完成。


## 播放舞台第二轮

加入可持久化的字号、背景与减少动效设置。手机底栏直接显示时间与可拖动进度；歌词根据标点优先按短句换行。封面背景在舞台模式播放时缓慢移动，暂停时停止，系统或用户要求减少动态效果时关闭动画。

生产预览在 Chrome 的 390 × 844 视口验证了放大歌词、柔焦背景、减少动效及刷新恢复。定位最后一行后检查歌词中心与可视区域中心相差小于 2 像素，随后通过底栏回到开头，验证首句开始前清除高亮并回到顶部。

## 两首配乐诗的词级同步

重新生成两首配乐诗的人声和混音，同时记录词起点。已核对 12 句共 94 个词起点与整句文字逐段吻合，所有词均落在对应人声段内。浏览器回归在暂停时定位《落日余温》3.8 秒，确认“最后”高亮；继续播放后切换到“一”。进入句后间奏会清除单词强调，往回拖到 3.4 秒会重新定位到“把”。行级居中、跨页播放和手机布局沿用同一套测试验证。
